Found while fixing, not reported by the review

- **The content sync prunes `content_revisions`, so the certificate's FK could vanish between the snapshot read and the insert.** This surfaced as two intermittent failures when the api and content suites ran in parallel against one database, and it is a real production race, not a test artefact. The snapshot now carries the repo and commit itself (immutable, which is the point of a snapshot), the verify page prefers those strings, and a foreign-key violation on insert retries once with a null revision id. Three consecutive full-suite runs are green.

Observations from the review, addressed

- PDF fonts are resolved from `import.meta.url` and would be missing from a standalone or Docker build: `outputFileTracingIncludes` now ships `packages/certificates/fonts` with the PDF route.
- The verify and profile pages called their loader twice per request (metadata and body): both are wrapped in `React.cache`.

Deliberate leftovers

- The course page still fetches the learner's certificate list to find one by course. It is one indexed query on a page that already runs several; a dedicated `byCourse` procedure can come with S8's dashboard work.
- Cloudflare R2 itself is unexercised until the bucket exists (founder action). MinIO covers the same S3 path locally and in CI.
