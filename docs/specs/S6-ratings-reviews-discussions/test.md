## Browser loop (Chrome, dev servers)

Driven by a Playwright script against the installed Chrome with throwaway accounts (learner, helper, mentor, seven-day-new account), plus signed-out checks in the Chrome session. Console clean on every page.

Flows: lesson page → discussion island loads after the body (its text is absent from the server HTML) → ask a question with a fenced code block, preview, post → "Mark as done" → feedback island appears in the completion slot → 4 stars, "Unclear" tag, a note → `lessons` row shows the new average, count, unclear count, and open-question count; helper replies → learner's inbox shows "replied to your question" → learner upvotes the reply (count 1); technical mentor accepts the answer (pinned first, badge) and watches the lesson; new account posts a link → "Waiting for a moderator" for the author, invisible to others → mentor sees the held comment with its reason in `/moderate`, approves → visible; mentor flags it; course page: review gated at 25 percent, form at 75 percent, review published with title and stars, `courses` aggregates move; course-level note posted; dark theme at 390 px on the lesson and course pages with no horizontal overflow.

Round 1 found: the discussion island read `emailVerified` from the session copy, so a learner who had just verified was told to verify again; the harness navigated away before "Mark as done" committed; replies and votes targeted the top thread rather than this run's.
Round 1 fixes: `comments.list` reads role and verification from the users table (the same rule S5 set for gated procedures); harness waits and scopes to its own thread.

Round 2: full loop green; three lint findings fixed (unused prop, two effect-driven `setState` calls replaced by initial state keyed on the loaded row); `review gated below 50 percent` now asserted after the island loads.

Round 3 (after code review, see `review.md`): edit re-runs the hold check, held comments are announced on approval, `reply_count` is recounted from source, the review form reads verification from the table, and Edit now seeds the textarea with the Markdown source. Full loop re-run green; screenshots regenerated.
