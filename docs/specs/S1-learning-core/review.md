# S1 review record

`/code-review high` ran on the S1 diff (16 verifier agents; 15 findings confirmed, 1 plausible, 1 refuted). Every confirmed finding was fixed before landing.

| #   | Finding                                                                                                                                                                     | Fix                                                                                                                                                                                                                                                                                                                                   |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Replay order `(occurredAt, recordedAt, id)` could not order a trigger event and its derived events (same timestamps, random uuid tie-break); rebuild was nondeterministic.  | Added `progress_events.seq` (bigint identity, unique). Replay orders by `seq` only. New test rebuilds a one-event history 10 times and asserts equality.                                                                                                                                                                              |
| 2   | Seed upgraded an existing `team@devhelp.pk` account to `admin` on every run.                                                                                                | `onConflictDoNothing` + lookup; seed refuses to run when `NODE_ENV=production`.                                                                                                                                                                                                                                                       |
| 3   | `enroll()` reused the auto-enrol idempotency key, so one-click enrol after a drop was a silent no-op; lesson events on a dropped enrolment never reactivated it.            | Derived events are keyed by their trigger event id (`…:derived:<eventId>`). `enroll()` returns `duplicate: true` without writing when already enrolled and keys re-enrolment by the drop time. `ensureEnrollment` treats `dropped` as absent. Tests: drop → enrol → drop → enrol; dropped learner keeps learning and completes again. |
| 4   | `course_completed` key had no per-enrolment component; a course could never be completed a second time after drop + re-enrol.                                               | Keyed by trigger event id. Reactivation clears `completedAt` / `progressPercent`. Test completes a course twice.                                                                                                                                                                                                                      |
| 5   | `ON DELETE SET NULL` on event subjects made `rebuildLearner` throw forever after a hard delete.                                                                             | `applyEvent` skips events whose subject is null. Test hard-deletes a course and rebuilds.                                                                                                                                                                                                                                             |
| 6   | `enrollmentCount` was bumped on every rebuild (fresh-insert heuristic, no emit gate).                                                                                       | Insert detection via `returning (xmax = 0)`; aggregate only moves when `emit` is true. Test asserts the count after two rebuilds.                                                                                                                                                                                                     |
| 7   | `lessons.course_id` could disagree with the module's course.                                                                                                                | Unique index `modules(id, course_id)` + composite FK `lessons(module_id, course_id) → modules(id, course_id)`. Migration reorders the index before the FK.                                                                                                                                                                            |
| 8   | Concurrency test was vacuous: pool `max: 1` outside production serialised every transaction.                                                                                | Pool size is `DATABASE_POOL_MAX` (default 10) everywhere. The test runs the race eight times.                                                                                                                                                                                                                                         |
| 9   | Seed rewrote `publishedAt` every run, could leave `isPublished` + `archivedAt` set, deleted/inserted questions non-atomically, never archived lessons it no longer emitted. | `publishedAt = coalesce(existing, now())`, `archivedAt: null` on upsert, questions replaced inside a transaction with validated options, stale lessons in seeded courses archived.                                                                                                                                                    |
| 10  | jsonb rule broken: `questions.answer` had no Zod schema, seed wrote options unvalidated, event payload schema duplicated.                                                   | `questionAnswerSchema` added; seed parses with `questionOptionsSchema`; `recordEventInput` uses `progressEventPayloadSchema`.                                                                                                                                                                                                         |

Also fixed from the cut list: per-kind payload Zod parsing now happens before the event insert; `quiz_attempted` / `exercise_submitted` / `project_submitted` require a lesson; indexes added on `lesson_progress.lesson_id`, `enrollments.last_lesson_id`, `path_courses.course_id`, `course_prerequisites.prerequisite_id`; unused `Executor` type removed; docs formatted; data-model entity map markers corrected.

Deliberately left: the small duplication of the `timestamps` column helper across schema files (three lines each, clearer than a shared import for schema readers); `seq` is a second unique key next to `id` (`id` stays the external identifier, `seq` is internal ordering).

Refuted: `transpilePackages` for `@repo/learning` is not needed until an app imports it (S3 will add it).
