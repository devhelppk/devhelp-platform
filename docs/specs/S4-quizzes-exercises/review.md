# S4 review record

`/code-review high` ran on the S4 diff. Its four angle reviewers (line-by-line, cross-file tracer, root-cause depth, conventions) completed; the final verification pass was cut off by a session rate limit, so each finding below was verified by hand against the code before it was fixed or set aside. Findings that only concerned S1 to S3 code and were already handled in those reviews are not repeated.

| 1   | **Python broken in production.** Turbopack only bundles `type: "module"` workers; the Pyodide worker was `type: "classic"` (for `importScripts`), so `next build` emitted `py.worker.ts` as a raw asset and every Python exercise would fail after deploy while the dev server worked. Confirmed in `.next/static/media`. | Both workers are module workers. The Python worker imports Pyodide's ESM build from the pinned CDN through a runtime `import()` the bundler cannot see. Deliberate leftovers

- `checkContentAsync` duplicates the solution-must-pass / starter-must-fail loop for the browser harness rather than folding it into `checkContent`. The two runs differ on purpose (vitest with the author's toolchain versus the learner's harness) and the duplication is 40 lines; merging them would make `checkContent` async for every caller. Left as is.
- `quizScoreFacts` reads `quiz_attempts` rather than folding `quiz_attempted` payloads in the reducer. The attempts table is the attempt store by design (decision 2) and the read happens inside the same transaction as the recompute, so replay stays deterministic. Left as is; revisit if attempts ever move out of Postgres.
- `AppShellContent` widened to `max-w-4xl` for every app-shell page, with `max-w-5xl` on assessment lessons. The reviewer preferred a local override; the founder asked for a wider content column in general during the loop, so the shared default moved.
- The exercise `runner` value for the in-house JS runner was still `sandpack` in content and the database (the content-schema enum predated dropping Sandpack). Renamed to `browser` in the clean-up after S4 (migration `0005`, content repo updated).
